# SDT Inventory

The mapping file contains provisional runtime targets for cluster, node, network, role, resource, CSV, volume, disk, S2D, Hyper-V, coverage, source, and relationship evidence.

These names are not declared canonical by this collector. KnowledgeContracts should ingest the released Contracts artifacts and collector evidence through its migration and compatibility process.

Storage identifiers retain NAA, WWN, serial, unique ID, LUN, and target-port values for vendor correlation.
