# Repo-ready contracts export

This folder is a **copy-ready export** intended for moving artifacts into the Contracts repo and/or Assembler repo.

## Provenance and copy model

- Files under `standards/` are **1:1 verbatim copies** from `.deps/contracts/standards/` at export time.
- `contracts.snapshot.json` is a **1:1 verbatim copy** from `.deps/contracts/contracts.snapshot.json` at export time.
- `manifest.json` is **newly generated by this repo** to describe what was exported, where it came from, and destination hints.
- This export does **not** modify schema contents; it mirrors selected existing artifacts into an independent folder.

## Why this exists

To avoid `.deps` path assumptions and allow direct copy into target repos.
